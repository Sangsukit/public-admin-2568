# คลังการประชุม คณะกรรมาธิการการบริหารราชการแผ่นดิน วุฒิสภา ปี 2568

เว็บไซต์: https://sangsukit.github.io/public-admin-2568/

จัดทำโดย คณะทำงานของ สว. โชติชัย บัวดิษ

เว็บไซต์นี้ไม่ใช่เว็บไซต์ทางการของวุฒิสภาหรือสำนักงานเลขาธิการวุฒิสภา บทสรุปเรียบเรียงจากเอกสารที่เผยแพร่ต่อสาธารณะบนระบบของรัฐสภา
หากข้อความใดต่างจากเอกสารต้นฉบับ ให้ถือตามเอกสารต้นฉบับ ภาพถ่าย: สำนักงานเลขาธิการวุฒิสภา
